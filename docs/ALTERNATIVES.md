## Documentation rollout

- **One root instruction file only:** less upkeep, but it would not provide project-specific flow, risks, or continuity.
- **Full guide file set with asserted operational facts:** more complete in appearance, but would risk inventing deployment, security, and database details.
- **Chosen approach:** root `AGENTS.md` plus focused `docs/` files with observed facts and clearly labeled unknowns.
